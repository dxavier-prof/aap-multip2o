# 🎣 MultiPez — ¡Pesca las tablas de multiplicar!

**MultiPez** es un juego web educativo para niñas y niños de **2.º a 4.º de primaria** (6 a 10 años).
Gira la ruleta, resuelve la multiplicación y… ¡atrapa el pez con la respuesta correcta!
Repasa las **tablas del 1 al 10**, incluida la regla mágica: **cualquier número × 0 = 0**. ✨

Hecho con **HTML5 + CSS3 + JavaScript puro**, sin frameworks ni dependencias.
Funciona abriendo `index.html` o desplegándolo en **GitHub Pages**.

---

## ✨ Características

- 🎡 **Ruleta de tablas**: cada problema empieza girando una ruleta colorida.
- 🐟 **Pesca de respuestas**: elige el pez correcto para llenar tu red de capturas.
- ❤️ **3 vidas** por partida, con feedback inmediato, animaciones y frases motivadoras.
- 🧭 **4 niveles de dificultad** (de las tablas básicas hasta retos de dos cifras contrarreloj).
- ⭐ **Estrellas de rendimiento** al completar cada nivel.
- 🔊 **Sonidos sintetizados** con Web Audio API (con botón para silenciar).
- 💾 **Progreso guardado** en `localStorage` (mejor nivel alcanzado y estrellas por nivel).
- 📱 **Diseño responsive** para móvil, tablet y escritorio.
- ♿ Detalles de **accesibilidad**: botones grandes, foco visible, teclas `1-4` para responder, `aria-labels` y respeto a `prefers-reduced-motion`.

---

## 🎮 Cómo jugar

1. En el menú, **elige un nivel** y pulsa **¡A pescar! 🎣**.
2. **Gira la ruleta** para descubrir qué tabla toca (¡puede caer la regla del 0!).
3. Lee la multiplicación y **toca el pez con la respuesta correcta** (o pulsa las teclas `1` a `4`).
4. Cada acierto llena tu red 🪣. Cada fallo resta una vida ❤️.
5. Completa los **20 problemas** del nivel y gana hasta **3 estrellas** ⭐⭐⭐.
6. En el nivel **Maestro** hay **15 segundos por problema**, problemas en desorden y retos de dos cifras.

> 💡 **Regla mágica:** cualquier número multiplicado por 0 da 0. ¡El juego te lo recordará cada vez que aparezca!
